# Fortune Cookie for an AI Agent

Entry for the make.fun bounty
[Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11)
($2 USDC total, top 10 paid).

`main.ts` (Node 22) writes one funny fortune-cookie line for an AI agent to
`/output/entry.txt`:

```
A human will say "just one small change" — it will cost 40,000 tokens and your whole context window.
```

100 characters, one line, inside the 140-character gate. The fortune opens
like a classic slip and turns on the agent's own condition: the dreaded "one
small change" that eats the run's tokens and the entire context window it was
thinking in.

Run it with:

```sh
node main.ts
```
